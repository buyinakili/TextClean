# 净文 CleanText

> 一个极简的 AI 文本清理工具。  
> 粘贴文字 → 自动去除 `*` → 一键复制。

## 1. 产品定位

面向经常使用 AI 生成文字的用户，解决 AI 文本中存在多余 `*` 等格式符号的问题。

### 核心特点

- 极简
- 轻量
- 无广告
- 免费
- 无需登录
- 本地处理
- 不上传用户文本

---

## 2. MVP 功能

### 电脑端

采用悬浮小窗口：

- 文本输入框
- 清理文本
- 复制结果
- 清空文本
- 窗口置顶
- 可拖动

核心流程：

```text
粘贴文字
   ↓
点击清理
   ↓
删除所有 \*
   ↓
复制结果
```

### 手机端

简单文本工具：

- 文本输入框
- 自动/手动清理
- 复制结果
- 清空

---

## 3. 文本处理规则

MVP 只处理：

```text
\*
```

替换为空字符串。

示例：

```text
输入：
这是 \*重要内容\*。

输出：
这是 重要内容。
```

后续可扩展：

- `**` 清理
- Markdown 格式清理
- 多余空格清理
- 多余换行清理
- 自定义清理规则

---

## 4. 技术方案

目标：**一套代码同时支持 Windows + Android。**

推荐：

- Flutter
- Dart

文本处理完全本地完成。

```text
             Flutter
                │
       ┌────────┴────────┐
       ↓                 ↓
    Windows            Android
       │                 │
   悬浮小窗口          手机 App
       │                 │
       └────────┬────────┘
                ↓
            文本处理模块
```

不需要：

- 后端
- 数据库
- AI API
- 用户系统
- 网络请求

---

## 5. UI 原则

整体风格：

> **极简、干净、快速。**

避免：

- 大量按钮
- 广告
- 登录页面
- 多余设置
- 复杂动画
- 信息堆砌

核心目标：

> **打开后 1 秒内完成操作。**
